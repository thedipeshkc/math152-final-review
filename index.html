Domain & Range — Master Cheat Sheet
screenshot this page before the exam
Core Rules
— three things break a function
Rule 1
Fraction: denominator ≠ 0. Set bottom = 0, solve, exclude that value.
Rule 2
Even root (√, ⁴√, …): inside ≥ 0. Set inside ≥ 0, solve for x.
Rule 3
Odd root (∛, ⁵√, …): no restriction. Domain is all real numbers.
If a function has two restrictions (e.g. fraction AND square root), apply both rules together and find the intersection.

Interval notation — bracket rules

( )
Parenthesis — number is NOT included
Use for excluded values, ±∞ always
[ ]
Square bracket — number IS included
Use when the endpoint satisfies the inequality
∞ and −∞ always use ( ).  |  ∪ means "or" — joins two pieces of the domain.
① Polynomial
f(x) = 2x³ − 5x + 1
No fractions, no roots, no logs. No restrictions ever.
Domain: (−∞, ∞)
② Rational (fraction)
f(x) = 1 / (x − 3)
Bottom ≠ 0 → x − 3 ≠ 0 → x ≠ 3
Domain: (−∞, 3) ∪ (3, ∞)
③ Square root (even root)
f(x) = √(x − 2)
Inside ≥ 0 → x − 2 ≥ 0 → x ≥ 2
Domain: [2, ∞)
④ Cube root (odd root)
f(x) = ∛x
Odd roots accept all reals including negatives. No restriction.
Domain: (−∞, ∞)
⑤ Square root in denominator
f(x) = 1 / √(x − 2)
Inside ≥ 0 and bottom ≠ 0 → x − 2 > 0 → x > 2
(zero is excluded because √0 = 0 makes the fraction undefined)
Domain: (2, ∞) ← parenthesis, 2 excluded
⑥ Fraction — two excluded values
f(x) = (x + 1) / (x² − 4)
Bottom ≠ 0 → x² − 4 ≠ 0 → x² ≠ 4 → x ≠ 2, x ≠ −2
Domain: (−∞,−2) ∪ (−2, 2) ∪ (2, ∞)
⑦ Combined restriction — root AND fraction
f(x) = √(x + 3) / (x − 1)
Two rules apply at once:
  ① Inside root ≥ 0 → x + 3 ≥ 0 → x ≥ −3
  ② Bottom ≠ 0 → x − 1 ≠ 0 → x ≠ 1
Combine: x ≥ −3 and x ≠ 1
Domain: [−3, 1) ∪ (1, ∞)
Math Notation Guide
how to read and write it correctly
Written as
(x + 1) / (7 − x)
fraction: numerator over denominator
Written as
√(x − 2)
square root — even root, needs inside ≥ 0
Written as
∛(2x + 5)
cube root — odd root, all reals allowed
Written as
(1/2)x³
½ times x cubed — coefficient is a fraction
Written as
f⁻¹(x)
inverse function — NOT 1/f(x)
Written as
(f ∘ g)(x)
composition: f(g(x)) — g runs first
Written as
[−3/8, ∞)
includes −3/8, goes to positive infinity
Written as
(−∞, 7) ∪ (7, ∞)
all reals except 7 — ∪ means "or"

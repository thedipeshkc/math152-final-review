Solving a Radical Equation

Question: Solve for x.
√(x + 9) + 3 = x
Progress
0 / 3 warmups
01   What is this asking?

A radical equation has a variable inside a square root. The trick is to isolate the root, then square both sides to remove it.

⚠ Warning — extraneous solutions
When you square both sides, you can accidentally create a fake solution. Always plug every answer back into the original equation. If it doesn't check out, it's extraneous — throw it away.

Key algebra fact used here: (x − 3)² = x² − 6x + 9
This is FOIL: (x − 3)(x − 3) = x·x − 3x − 3x + 9

The last step gives two possible answers: x = 0 or x = 7. But one of them is fake (extraneous). The full solve shows why.

Radical Equation
— isolate root, square, check
Step 1
Isolate the root: get √(...) alone on one side. Move everything else to the other side.
Step 2
Square both sides: (√A)² = A. The root disappears. Expand the other side carefully — use FOIL if needed.
Step 3
Solve the resulting equation. It may be quadratic — factor or use the quadratic formula.
Step 4
Check EVERY answer in the original equation. Cross out any that don't work (extraneous solutions).
FOIL reminder: (a − b)² = a² − 2ab + b²
(x − 3)² = x² − 6x + 9  |  (x + 3)² = x² + 6x + 9
04   Solve it
following the cheat sheet exactly
1
Isolate the square root
Move +3 to the right side:
√(x + 9) + 3 = x
√(x + 9) = x − 3
2
Square both sides
Left: (√(x+9))² = x + 9.   Right: (x−3)² — use FOIL:
(√(x + 9))² = (x − 3)²
x + 9 = x² − 6x + 9
FOIL: (x−3)(x−3) = x² − 3x − 3x + 9 = x² − 6x + 9
3
Rearrange — get everything on one side
Subtract (x + 9) from both sides:
0 = x² − 6x + 9 − x − 9
0 = x² − 7x
Factor out x:
0 = x(x − 7)
4
Solve — two candidates
x = 0   or   x = 7
5
Check both in the ORIGINAL equation: √(x+9)+3 = x
Check x = 0:
√(0+9) + 3 = √9 + 3 = 3 + 3 = 6   but right side = 0   6 ≠ 0 ✗
x = 0 is EXTRANEOUS — throw it out.
Check x = 7:
√(7+9) + 3 = √16 + 3 = 4 + 3 = 7   and right side = 7   ✓
Final Answer
x = 7
x = 0 was extraneous
One valid solution
Always check both
Why does x = 0 fail?
When we squared both sides in Step 2, we also accidentally created solutions for √(x+9) = −(x−3). Squaring hides the sign. That's why x = 0 appeared — it satisfies the squared version but not the original. This is why checking is mandatory.

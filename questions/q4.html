Solving a System of Equations

Question: Solve using the substitution method.
x − 2y = 8
x = y + 5
Progress
0 / 3 warmups
01   What is this asking?

A system of equations is just two equations at the same time. You need to find the one point (x, y) that makes BOTH equations true simultaneously.

Three possible outcomes
One solution: Two lines cross at exactly one point. You get a unique x and y.

Infinitely many solutions: Same line — every point works. Algebra gives 0 = 0 (always true).

No solution: Parallel lines — never cross. Algebra gives something like 0 = 5 (impossible).

Substitution method: One equation already tells you what x equals. Plug that into the other equation — you're left with only one variable. Solve it.

Substitution Method
— 5 steps, always the same
Step 1
Find the equation where one variable is already isolated (alone on one side). That's your substitution equation.
Step 2
Substitute: replace that variable in the OTHER equation with the expression. Now you have only one variable.
Step 3
Solve the single-variable equation. Combine like terms, isolate the variable.
Step 4
Back-substitute: plug your answer into either original equation to find the second variable.
Step 5
Verify: plug (x, y) into BOTH original equations. Both must be true.
If you get 0 = 0 → infinitely many solutions (same line).
If you get 0 = 5 (false) → no solution (parallel lines).

Infinitely many: in the middle of solving, you'd get something like 0 = 0 or 8 = 8. Stop — same line.

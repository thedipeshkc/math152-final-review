What is slope?

Slope = how steep a line is. It measures how much y changes for every 1 unit x moves right.

slope = rise / run  =  change in y / change in x  =  (y₂ − y₁) / (x₂ − x₁)

m > 0
Positive slope
Line goes up left→right
m < 0
Negative slope
Line goes down left→right
m = 0
Zero slope
Flat horizontal line
m = ?
Undefined
Vertical line (x = k)

What is the distance formula?

The distance between two points is the length of the straight line connecting them. It comes from the Pythagorean theorem: the horizontal and vertical gaps form the two legs of a right triangle, and the distance is the hypotenuse.

Distance Formula
d = √[ (x₂ − x₁)² + (y₂ − y₁)² ]

Exam trick: Always subtract in the same order — (x₂−x₁) and (y₂−y₁). It doesn't matter which point is "1" because you're squaring both anyway. Squaring removes the negative.

Step 2
Subtract the y-coordinates: (y₂ − y₁). Square the result.
Step 3
Add both squares. Take the square root. Simplify the radical if possible.
Round

Simplify √136: factor out perfect squares. 136 = 4 × 34 → √136 = √4 · √34 = 2√34. Always simplify before approximating.
Solve it — (−7,−9) to (3,−15)
1
Label the points
(x₁, y₁) = (−7, −9)  |  (x₂, y₂) = (3, −15)
2
Subtract x-coordinates, then square
x₂ − x₁ = 3 − (−7) = 3 + 7 = 10
(10)² = 100
3
Subtract y-coordinates, then square
y₂ − y₁ = −15 − (−9) = −15 + 9 = −6
(−6)² = 36
Negative squared becomes positive. Good.
4
Add and take square root
d = √(100 + 36) = √136
5
Simplify the radical
Factor 136 to find perfect square factors: 136 = 4 × 34
√136 = √(4 × 34) = √4 · √34 = 2√34
6
Round to three decimal places
Calculator: √34 ≈ 5.83095189...
Multiply by 2: 2 × 5.83095... = 11.66190...
Look at 4th decimal: 11.6619... → 4th digit = 9 ≥ 5 → round up 3rd decimal
Result: 11.662
Final Answer
Exact: 2√34  |  Approximate: 11.662
Rounding rule — never forget
Three decimal places = keep 3 digits after the decimal.
Look at the 4th digit: if it's 5, 6, 7, 8, or 9 → the 3rd digit goes up by 1.
If it's 0, 1, 2, 3, or 4 → leave the 3rd digit as is.

Parallel vs Perpendicular

All line relationship questions come down to slope. Two key rules:

Parallel: same slope  m₁ = m₂
Perpendicular: slopes are negative reciprocals  m₁ × m₂ = −1
Negative reciprocal — how to find it
Flip the fraction AND change the sign.
m = 3/4 → perpendicular slope = −4/3
m = −3 = −3/1 → perpendicular slope = 1/3
m = 2/5 → perpendicular slope = −5/2

To write the equation of a line through a given point, use point-slope form:
y − y₁ = m(x − x₁)   then rearrange to y = mx + b.

What is this asking?

Given a graph (or two points on a line), write the equation in slope-intercept form: y = mx + b.

You need two things: the slope (how steep) and the y-intercept (where it crosses the y-axis).

Slope from two points
m = (y₂ − y₁) / (x₂ − x₁)

Once you have m, either read b from the graph (the point where x = 0) or use point-slope form to calculate it.

Solve it — points (0,−2) and (1,−4)
1
Calculate the slope
m = (y₂ − y₁) / (x₂ − x₁)
m = (−4 − (−2)) / (1 − 0)
m = (−4 + 2) / 1 = −2/1 = −2
2
Read the y-intercept
One of the given points is (0, −2). That's where x = 0, so b = −2 directly.
b = −2   → y-intercept = (0, −2)
3
Write the equation
y = mx + b = −2x + (−2)
y = −2x − 2
Final Answer
y = −2x − 2
Slope = −2
y-intercept = (0, −2)

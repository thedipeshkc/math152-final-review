Question 3 of 12

Inverse Functions

Question: For the one-to-one function f(x) = (1/2)x³ − 5, find the inverse f⁻¹(x).
Give the domain and range for both f and f⁻¹.
Progress
0 / 3 warmups
01   What is this asking?

An inverse function undoes what the original function did.

If f takes x in and gives y out, then f⁻¹ takes y in and gives x back.

Real life example
f = "put on your shoes."   f⁻¹ = "take off your shoes." One undoes the other. You end up exactly where you started.

The question also asks for domain (x values allowed) and range (y values that come out).

Key rule: Domain of f = Range of f⁻¹, and Range of f = Domain of f⁻¹. They always swap.

algebra you'll need for the solve

If y = x + 5, solve for x. What does x equal? (x = y − ?)
If y = x/2, solve for x. (x = y × ?)
What is ∛8? (cube root of 8)
Those three steps — move constants, multiply both sides, take cube root — are exactly what we'll do to find the inverse.

Domain/Range
They swap: Domain of f = Range of f⁻¹. Range of f = Domain of f⁻¹. For a cubic polynomial with no restrictions → both are (-∞, ∞).
Cube root vs square root: √x needs x ≥ 0. But ∛x works for ANY number including negatives. So ∛(−8) = −2 is totally fine.
04   Solve it
following the cheat sheet
1
Replace f(x) with y
y = (1/2)x³ − 5
2
Swap x and y
Every x becomes y, every y becomes x.
x = (1/2)y³ − 5
3
Solve for y — step by step
Add 5 to both sides:
x + 5 = (1/2)y³
Multiply both sides by 2:
2(x + 5) = y³
Take the cube root of both sides:
y = ∛( 2(x + 5) )
4
Write as f⁻¹(x)
f⁻¹(x) = ∛( 2(x + 5) )
5
Domain and range
f(x) = (1/2)x³ − 5 is a cubic polynomial — no fractions, no square roots. Any x works. Domain = (−∞, ∞). As x goes from −∞ to ∞, so does f(x). Range = (−∞, ∞).

f⁻¹(x) = ∛(2(x+5)) has a cube root — cube roots accept ALL real numbers including negatives. Domain = (−∞, ∞). Range = (−∞, ∞).
Final Answer
f⁻¹(x) = ∛(2(x + 5))

How to verify your inverse is correct
Plug f(x) into f⁻¹ — you should get x back.
f⁻¹(f(x)) = ∛(2((1/2)x³−5+5)) = ∛(2·(1/2)x³) = ∛(x³) = x ✓

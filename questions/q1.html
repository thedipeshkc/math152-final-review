Finding the Domain of a Function

Question: Find the domain of the function    f(x) = (x + 1) / (7 − x)
Progress
0 / 3 warmups
01   What is this asking?

Domain = all the numbers you are allowed to plug in as x.

Most of the time any number works. But three things break a function:

Divide by zero
Like 1/0 — undefined. Not allowed.
Square root of negative
Like √(−4) — not a real number.
Log of zero or negative
Like log(0) — undefined.

This question has a fraction. So the only rule we care about: bottom of fraction ≠ 0

02   Warmup
answer all 3 to build confidence

Notice: All three answers lead to the same thing — x = 7 is the only problem. Exclude it from the domain.
03   Cheat sheet
screenshot this — works for ANY rational function
Rational Function Domain
— works every time
Rule
Rational function = any fraction. Only restriction: denominator ≠ 0.
Step 1
Look at the bottom only. Ignore the top completely.
Step 2
Set bottom ≠ 0 and solve for x. That value is excluded.
Step 3
Write domain as: (-∞, a) ∪ (a, ∞) where a is the excluded value.
Brackets
( ) = number NOT included  |  [ ] = number IS included. Excluded values always use ( ).
If bottom has x² → two excluded values. Exclude both. Domain splits into 3 pieces.
04   Solve it
following the cheat sheet
1
Identify the type
f(x) = (x+1)/(7−x) is a fraction → rational function. Only rule: bottom ≠ 0.
2
Set denominator ≠ 0
7 − x ≠ 0
3
Solve for x
−x ≠ −7
x ≠ 7
x = 7 gives 8/0 — undefined. Every other number is fine.
4
Write the domain
All real numbers except 7. Split at 7, use ( ) because 7 is excluded.
Final Answer
Domain = (−∞, 7) ∪ (7, ∞)
All reals except x = 7
( ) = 7 not included
∪ = "or", joins the two halves
Quick verify — always do this
Plug x = 7: (7+1)/(7−7) = 8/0 = undefined ✓ right to exclude.
Plug x = 5: (5+1)/(7−5) = 6/2 = 3 ✓ works fine, so 5 is in the domain.
Test any value of x
See instantly whether it's in the domain or not.

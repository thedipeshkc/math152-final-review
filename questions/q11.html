① Plain English
what is this question actually asking?

A logarithmic equation has a log (or ln) with an unknown variable inside it. Your goal is to get rid of the log so you can solve for x (or t) like normal.


Part A — You have two logs being added on the left side. The product rule lets you smash them into one single log. Once you have one log equal to a number, you can rewrite it in exponential form and solve the resulting quadratic.


Part B — The variable t is stuck in the exponent of e. The reverse of eˣ is ln (natural log). Take ln of both sides to bring t down, then divide. Always round to 3 decimal places unless told otherwise.


Key difference: log means base 10  ·  ln means base e ≈ 2.718. When no base is written, assume base 10.

④ Step-by-Step Solution
full worked solution with live calculator
Part A
log x + log(x + 3) = 1
1
Identify the base
No base is written, so log means log base 10.
log₁₀ x + log₁₀(x + 3) = 1
2
Combine logs — Product Rule
log A + log B = log(A·B). Combine both logs on the left into one.
log₁₀[x(x + 3)] = 1
3
Rewrite in exponential form
log₁₀(X) = 1 means 10¹ = X. So:
x(x + 3) = 10¹ = 10
4
Expand and solve the quadratic
Distribute, move everything to one side, then factor.
x² + 3x = 10
x² + 3x − 10 = 0
(x + 5)(x − 2) = 0
x = −5   or   x = 2
5
Check for extraneous solutions
log(x) requires x > 0. Check each candidate:
x = −5: log(−5) is undefined ✗
x = 2: log(2) + log(5) = log(10) = 1 ✓
Final Answer — Part A
x = 2
x = −5 rejected (log of negative undefined)
verified: log 2 + log 5 = log 10 = 1 ✓
Alternative Method — Rewrite 1 as log(10)
Since log(10) = 1, rewrite the equation as:
log x + log(x+3) = log(10)
Combine left side: log[x(x+3)] = log(10)
Since log is one-to-one: x(x+3) = 10 → same quadratic → same answer.
Part B
e−0.94t = 0.01 — solve for t
1
Take ln of both sides
The base is e, so use natural log (ln) to undo the exponential.
ln(e^(−0.94t)) = ln(0.01)
2
Simplify the left side
Rule: ln(eˣ) = x. The ln and e cancel perfectly.
−0.94t = ln(0.01)
3
Solve for t — divide both sides by −0.94
t = ln(0.01) / (−0.94)
4
Simplify ln(0.01) — exact form
0.01 = 10⁻², so ln(0.01) = ln(10⁻²) = −2·ln(10)
t = (−2 ln 10) / (−0.94) = (2 ln 10) / 0.94
Exact: t = (100 ln 10) / 47
5
Approximate to 3 decimal places
ln(10) ≈ 2.302585 → 2 × 2.302585 = 4.60517 → ÷ 0.94
t ≈ 4.60517 / 0.94 ≈ 4.89912… → t ≈ 4.899
4th decimal is 1 (below 5) → 3rd decimal stays as 9 → 4.899
Final Answer — Part B
t = (2 ln 10) / 0.94 ≈ 4.899
exact: (100 ln 10) / 47
rounded to 3 decimal places

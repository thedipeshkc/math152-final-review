Solving a Rational Equation

Question: Solve for x.
6 / (x + 7) = 8 / x
Progress
0 / 3 warmups
01   What is this asking?

A rational equation is any equation that has a variable in a denominator (bottom of a fraction). The strategy: cross-multiply to kill the fractions, then solve normally.

Critical rule — restrictions first
Before solving, find what x values make any denominator = 0. Those values are forbidden. Even if algebra gives you that answer, you must throw it out (it's called an extraneous solution).

Cross-multiplication rule: if you have one fraction = one fraction, you can multiply diagonally — top-left × bottom-right = top-right × bottom-left.

a/b = c/d   →   a·d = b·c

Rational Equation
— fraction = fraction → cross-multiply
Step 1
Find restrictions: set each denominator = 0, solve. Those x-values are forbidden. Write them down.
Step 2
Cross-multiply: top-left × bottom-right = top-right × bottom-left. This removes all fractions.
Step 3
Expand and simplify. Combine like terms, get all x on one side.
Step 4
Solve for x.
Step 5
Check restriction: if your answer matches a forbidden value, throw it out (no solution). Otherwise, verify in original equation.
Always verify by plugging back into the original. Both sides must give the same number.
04   Solve it
following the cheat sheet exactly
1
Find restrictions (forbidden x-values)
Set each denominator = 0 and solve:
x + 7 = 0  →  x = −7   (forbidden)
x = 0   (forbidden)
If our answer turns out to be −7 or 0, we throw it out.
2
Cross-multiply
One fraction = one fraction → multiply diagonally:
6 / (x + 7) = 8 / x
6 · x = 8 · (x + 7)
3
Expand the right side
6x = 8x + 56
4
Solve for x — move x terms to one side
6x − 8x = 56
−2x = 56
x = −28
5
Check restriction
Our answer is x = −28. Forbidden values were −7 and 0.
−28 ≠ −7   and   −28 ≠ 0   ✓   Allowed!
Final Answer
x = −28
Not an extraneous solution
One valid solution
Verify by plugging x = −28 into the original
Left side: 6 / (−28 + 7) = 6 / (−21) = −2/7
Right side: 8 / (−28) = −2/7
−2/7 = −2/7 ✓   Both sides match. Correct.

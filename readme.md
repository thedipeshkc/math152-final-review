## 📘 MATH152 Final Review — Interactive Study Guide
This project is a fully interactive review tool designed to help students prepare efficiently for the MATH152 final exam. It contains 12 essential questions, each chosen because they represent the easiest, most predictable, and most high‑value topics that typically appear on exams.

## The goal is simple:
Master these 12 first — build confidence — then move on to harder problems.

## 🎯 What’s Inside Each Question Page
Every question page includes:
Plain‑English explanation of the concept
Warmup exercises to build intuition
A cheat sheet you can screenshot
A full step‑by‑step solution
Progress bar to track where you are
Navigation buttons to move between questions or return home
This structure helps students learn quickly without feeling overwhelmed.

## 🛠️ Technologies Used
HTML5 — page structure
CSS3 — shared styling and layout
Vanilla JavaScript — progress bars, navigation, and interactive elements
GitHub Pages — hosting and deployment

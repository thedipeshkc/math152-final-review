Question 2 of 12

Function Composition

Question: Find (f ∘ g)(x) and (g ∘ f)(x) and the domain of each.
f(x) = 8x + 3
g(x) = √x
Progress
0 / 3 warmups
01   What is this asking?

You have two functions. Think of them as two machines you chain together.

Machine f
f(x) = 8x + 3
multiply by 8, then add 3
→
Machine g
g(x) = √x
take the square root

(f ∘ g)(x) — run g first, feed that result into f.
(g ∘ f)(x) — run f first, feed that result into g.

Domain tells us: which x values are actually allowed? Some values will break the square root, so we need to check.

02   Warmup
same functions — just substitution practice
Build confidence before the real thing
f(x) = 8x + 3. What is f(2)?
g(x) = √x. What is g(4)?
f(x) = 8x + 3. What is f(√4)?
The aha moment: That last one — f(√4) — is exactly what (f ∘ g)(4) means. You just did composition without realizing it!
03   Cheat sheet
screenshot this — works every time
Function Composition
— always the same 4 steps
Step 1
Write what it means: (f ∘ g)(x) = f(g(x)) — right side goes inside left side.
Step 2
Take the outer function. Replace every x in it with the entire inner function.
Step 3
Simplify the result.
Domain
Square roots need inside ≥ 0. Fractions need bottom ≠ 0. Use the strictest rule from both functions.
Order always matters — (f ∘ g) and (g ∘ f) give different answers. Always do them separately.
04   Solve it
following the cheat sheet
Part A
Find (f ∘ g)(x)
1
Write what it means
f goes outside, g goes inside.
(f ∘ g)(x) = f( g(x) )
2
Replace every x in f with g(x) = √x
f(x) = 8x + 3. Every x becomes √x.
f( √x ) = 8(√x) + 3
3
Simplify
(f ∘ g)(x) = 8√x + 3
4
Find the domain
g(x) = √x requires x ≥ 0. f has no restriction. So domain comes from g.
x ≥ 0
Answer — Part A
(f ∘ g)(x) = 8√x + 3
Domain: x ≥ 0
Interval: [0, ∞)
[ because x = 0 IS included
Why is x = 0 included? A very common confusion.
✓ √0 = 0   allowed
✓ √4 = 2   allowed
✗ √(−1)   NOT real
✗ √(−9)   NOT real
The rule is inside ≥ 0, not inside > 0. Zero is fine because √0 = 0. That's why we write [0, ∞) with a square bracket — bracket means the number is included.
Part B
Find (g ∘ f)(x)
1
Write what it means — order flipped
(g ∘ f)(x) = g( f(x) )
2
Replace every x in g with f(x) = 8x+3
g(x) = √x. Every x becomes (8x + 3).
g( 8x+3 ) = √(8x + 3)
3
Find the domain
Inside of the square root must be ≥ 0. Solve:
8x + 3 ≥ 0
8x ≥ −3
x ≥ −3/8
Answer — Part B
(g ∘ f)(x) = √(8x + 3)
Domain: x ≥ −3/8
Interval: [−3/8, ∞)
Key takeaway — the two answers are different
Part A gave 8√x + 3. Part B gave √(8x+3). Completely different functions, completely different domains. This always happens when you swap the order. That's why the question asks for both.

Slope, Y-Intercept & Graphing

Question: List the slope and y-intercept. Then graph.
f(x) = 3x − 2
Progress
0 / 3 warmups
01   What is this asking?

Any straight line can be written as:  y = mx + b

m = slope
How steep the line is. Rise ÷ Run. How much y changes per 1 step in x.
b = y-intercept
Where the line crosses the y-axis. The value of y when x = 0.

What slope means visually:

↗
Positive slope
line goes up-right
↘
Negative slope
line goes down-right
→
Slope = 0
flat horizontal line
↕
Undefined slope
vertical line

Slope formula from two points (x₁,y₁) and (x₂,y₂):

m = (y₂ − y₁) / (x₂ − x₁)   =   rise / run

All Line Equations
— slope, forms, parallel, perpendicular
Slope
m = (y₂ − y₁) / (x₂ − x₁). Rise over run. Subtract y's on top, subtract x's on bottom. Same order both times.
Slope-Intercept
y = mx + b — m is slope, b is y-intercept. Best for reading slope and graphing.
Point-Slope
y − y₁ = m(x − x₁) — use when you know a point (x₁, y₁) and slope m. Best for building an equation from a point.
Standard Form
Ax + By = C — no fractions, all integers. Convert from slope-intercept by multiplying through.
Parallel
Same slope, different intercept. If original slope is m, parallel slope is also m.
Perpendicular
Slope flips and changes sign: −1/m (negative reciprocal). If slope = 3, perpendicular slope = −1/3. If slope = −3/4, perpendicular slope = 4/3.
How to graph: Plot the y-intercept (0, b). Then use slope = rise/run to find next point. Draw a line through both points.

02   Warmup
reading slope-intercept form
Read slope and intercept directly from f(x) = 3x − 2
In y = mx + b, what is m (slope) for f(x) = 3x − 2?
What is b (y-intercept value) for f(x) = 3x − 2?
Using slope 3 = 3/1, from (0,−2) go up 3, right 1. What is the y-value at x = 1?
Those three pieces are all you need to graph: y-intercept, slope, second point. Plot two points, draw the line.
04   Solve it
reading the equation and graphing
1
Identify slope-intercept form
f(x) = 3x − 2 is already in y = mx + b form:
y = 3x + (−2)   →   m = 3,   b = −2
2
Read the slope
m = 3 = 3/1   (rise 3, run 1)
For every 1 step right, y goes up by 3. Positive slope = line rises left to right.
3
Read the y-intercept
b = −2   →   point: (0, −2)
The line crosses the y-axis at −2. This is your first plot point.
4
Find a second point using slope
From (0, −2), go up 3, right 1:
Second point: (0+1, −2+3) = (1, 1)
Final Answer
Slope = 3  |  Y-intercept = (0, −2)
m = 3 (rises steeply)
b = −2
Points: (0,−2) and (1,1)
